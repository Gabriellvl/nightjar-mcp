# Contributing to nightjar-mcp

PRs welcome 🌑. `npm install && npm run dev`. Keep tools small and well-described. One change per PR. Ping @gabe_maxxing. #jointhearmy

Open a pull request against `main` with the reason for the change and how you tested it. Run `npm run build` before submitting. Gabriel reviews each contribution after the checks and decides whether to merge it or request changes.
